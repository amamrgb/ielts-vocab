# 雅思备考 · 词汇分类工作台

单文件网页版雅思词汇学习工具，包含三大词库：

| 词库 | 词量 | 分类方式 |
|---|---|---|
| 刘洪波《雅思词汇真经》 | 3582 | 22 个 Unit 主题 + 高频/低频 |
| 王陆《雅思听力语料库》 | 按章节 | Chapter 4 / 12 / 8 / 11 / 5 / 3 |
| 刘洪波阅读考点词 | 538 | 一类（超高频）/ 二类（重点）/ 三类（基础） |

功能：分级背词、拼写听写、收藏夹练习、词根练习（69 组词根/前缀）、复习曲线、发音。

## 使用方式

直接打开网页即可，无需安装、无需登录服务器：

- 输入昵称进入（昵称只用于区分本机上的多个使用者）
- 学习进度保存在**本机浏览器**（localStorage）
- 换手机/电脑：旧设备点「⬇ 导出进度」，新设备点「⬆ 导入进度」选文件即可搬家

## 部署

整站就是 `index.html` 一个文件，任何静态托管都能用：

- GitHub Pages：本仓库 Settings → Pages → Source 选 `main` 分支根目录
- 或直接把 `index.html` 丢到任意静态空间 / 网盘直链 / 本地双击打开

## 目录

```
index.html        完整应用（词库、样式、逻辑全部内联）
server/server.py  早期多用户后端版本（Flask + SQLite，含封禁/白名单接口，仅供参考）
```

> 单机版不依赖 `server/` 目录，删除也不影响使用。
